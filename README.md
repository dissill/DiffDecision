# 🍎 DiffDecision：多AI差异决策助手

> **别人给答案，我们给差异和代价。**

DiffDecision 不是又一个 AI 聊天机器人。它调用多个 LLM，提取不同意见，把不同意见变成可拖动的变量，实时算出变量对结果的影响，推荐可解释、可权衡的方案。

## 🎯 核心定位

单个 AI 会漏掉关键变量，而你往往不知道自己不知道什么。DiffDecision 把多个 AI 的不同意见，变成你能拖动的决策仪表盘。

## 📋 功能模块

| 模块 | 说明 |
|------|------|
| 输入区 | 输入需求，生成方案 |
| 多模型卡片 | DeepSeek / GPT / Claude / Gemini / Qwen 各自输出关键词 + 方案摘要 |
| 关键词热力图 | 模型 × 关键词矩阵，颜色深浅表示强调程度 |
| 差异关键词排序 | 按权重排序的水平条形图，可点击切换 |
| 变量对照面板 | 对照表 + 4 个滑块，实时计算营业额、利润率、净利润 |
| 推荐方案 | 综合高共识词 + 正向差异词，附推荐理由 |
| 对比实验 | 单模型 vs 多模型投票 vs DiffDecision |

## 🚀 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 启动应用
streamlit run app.py --server.port 8080
```

浏览器访问 `http://localhost:8080`

## 📊 演示场景

输入："我想卖苹果，给我一个销售方案。"

五个模型给出不同关键词：

| 模型 | 关键词 | 方案摘要 |
|------|--------|----------|
| DeepSeek | 电商平台、冷链物流、品牌溢价、社区团购 | 做高端苹果，走电商和社区团购 |
| GPT | 城市批发市场、电商、品牌化、供应链金融 | 先铺城市批发，再拿供应链金融放大 |
| Claude | 乡村集市、电商、合作社模式、地理标志认证 | 用合作社整合农户，打地理标志，进乡村集市 |
| Gemini | 城市零售、电商、冷链、出口贸易 | 城市零售为主，尝试出口 |
| Qwen | 直播带货、电商、产地直发、乡村旅游采摘 | 直播+产地直发，结合乡村旅游采摘 |

## ⚖️ 对比实验

| 指标 | 单模型 | 多模型投票 | DiffDecision |
|------|--------|-----------|-------------|
| 覆盖关键词数 | 4 | 6 | 9 |
| 发现差异关键词 | 0 | 2 | 5 |
| 量化影响的关键词 | 0 | 0 | 4 |
| 可交互变量 | 0 | 0 | 4 |
| 推荐方案可解释性 | 低 | 中 | 高 |
